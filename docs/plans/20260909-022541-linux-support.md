# vsummary Linux 支持实现计划

目标:让项目在 Linux(优先 Ubuntu 22.04/24.04,内核 5.15+)上以**源码方式**稳定运行;**只**交付源码版跑通,**不**做 Pack 打包脚本,**不**做 AMD 显卡路径。

仿照现有 Windows 路径(`start.bat` + PowerShell 打包 + Windows-only DLL 处理),逐个替换为跨平台或 POSIX 分支。所有改动保持最小入侵,不影响现有 Windows / macOS 行为。

---

## 0. 总体原则

- **分支策略**:用 `sys.platform` / `os.name` 在原位置加 `if/else`,不引入新的抽象层。
- **不动 Windows 行为**:所有 `os.name == "nt"` 分支保持等价语义;POSIX 分支只在它缺席时报错/退化时补齐。
- **逐项可独立验证**:每一节都给出"在 Linux 上验证什么"的具体方法。
- **Pack 不在范围**:本计划**只**交付"源码版"在 Linux 上跑通;`scripts/build_release.ps1` 维持现状,新增 Linux Pack 打包脚本另起一个 issue。
- **GPU 在范围但做有限承诺**:支持 NVIDIA CUDA 12;AMD 不在本计划范围,只确保不会因为缺 powershell 而崩溃;CPU 路径默认就能跑。

## 1. 启动脚本:新增 `start.sh`

**文件**: `start.sh`(新增,可执行权限)

仿照 `start.command` 的 macOS 脚本但替换两处 Linux 限制:

- `lsof -iTCP:8001` / `lsof -iTCP:4173` → 改用 Python 一行端口探测(避免依赖 `lsof`)。

脚本内容与已批准的 plan 一致(conda 发现 → 环境检查 → `npm`/`ffmpeg` 校验 → 端口探测 → 后端/前端 nohup 启动 → `xdg-open` 打开浏览器)。

**不动** `start.bat` 和 `start.command`,验证:

```bash

```

## 3. 应用更新:补全 POSIX 分支(必做,含现有 bug 修复)

**文件 A**: `updater/apply_and_restart.py`

当前 `_is_process_running` 的 `if os.name != "nt"` 之后**没有 return**,Linux 上会继续走到 `ctypes.windll` 崩溃。修正:

```python
def _is_process_running(pid: int) -> bool:
    if os.name != "nt":
        try:
            os.kill(pid, 0)
        except ProcessLookupError:
            return False
        except PermissionError:
            return True
        return True
    kernel32 = ctypes.windll.kernel32
    ...
```

只需把现有 POSIX 分支末尾补一个 `return True`(成功时由 try 内分支返回;失败已被 except 捕获;当前缺的就是这条 `return True` 让 Windows 分支永远不会执行)。

同时把 `_restart_pack` 改成平台相关:

```python
def _restart_pack(root: Path) -> None:
    if os.name == "nt":
        start_script = root / "start.bat"
        subprocess.Popen(
            ["cmd.exe", "/c", "start", "", str(start_script)],
            cwd=root, close_fds=True,
            creationflags=_background_process_flags(),
            stdin=subprocess.DEVNULL,
            stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL,
        )
        return
    # POSIX:在 xterm/-/setsid 下后台运行,避免关闭 shell 时被打断
    start_script = root / "start.sh"
    if not start_script.is_file():
        raise RuntimeError(f"Pack 启动脚本缺失: {start_script}")
    subprocess.Popen(
        ["/bin/bash", str(start_script)],
        cwd=root, close_fds=True,
        start_new_session=True,
        stdin=subprocess.DEVNULL,
        stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL,
    )
```

`_background_process_flags` 已经 `getattr(..., 0)` 兜底,在 Linux 上返回 0 是正确的——不需要改。

**文件 B**: `src/backend/api/application_update.py`

```python
def _is_pack_installation(root: Path) -> bool:
    python_rel = "python.exe" if os.name == "nt" else "bin/python"
    return all(
        path.is_file() for path in (
            root / "VERSION",
            root / "updater" / "installed.json",
            root / "updater" / "config.json",
            root / "runtime" / python_rel,
        )
    )
```

`_background_process_flags` 在此文件里也用了 Windows 常量,POSIX 上 `getattr(..., 0)` 已经兜底返回 0,但 `subprocess.Popen` 调用本身没问题;**不强制改**,仅当发现关闭终端会带走更新器时再补 `start_new_session=True`。本计划**留作后续观察项**。

## 5. B 站扫码登录浏览器发现:补 Linux 路径

**文件**: `src/backend/bilibili/ytdlp_bilibili.py`,改 `_resolve_default_browser_path`:

```python
def _resolve_default_browser_path(*, exists: Callable[[Path], bool] | None = None) -> str | None:
    path_exists = exists or Path.exists
    if os.name == "nt":
        program_files = [os.environ.get("PROGRAMFILES"), os.environ.get("PROGRAMFILES(X86)")]
        candidates = [
            ("Google", "Chrome", "Application", "chrome.exe"),
            ("Microsoft", "Edge", "Application", "msedge.exe"),
        ]
        for parts in candidates:
            for base in (p for p in program_files if p):
                c = Path(base).joinpath(*parts)
                if path_exists(c): return str(c)
        return None
    # POSIX:DrissionPage 也能不指定二进制走系统默认;优先 PATH 中的可执行名
    for name in ("google-chrome", "chromium", "chromium-browser", "microsoft-edge", "chrome"):
        resolved = shutil.which(name)
        if resolved: return resolved
    return None
```

`shutil` 顶部需补 `import shutil`(原文件没 import)。

## 8. `diagnose_gpu.py`:加平台守卫

**文件**: `diagnose_gpu.py`

**最小改动**:在 `main()` 顶部加:

```python
if sys.platform != "win32":
    print("diagnose_gpu.py 当前仅服务于 Windows 整合包自检;Linux 源码版请直接运行 start.sh。")
    return 0
```

保留现有逻辑,只在非 Windows 上提早退出。
